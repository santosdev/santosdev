# Dashboard de Análise de Vendas
**Painel de vendas no Power BI** &nbsp;|&nbsp; [Repositório](https://github.com/santosdev/dashboard-analise-de-vendas)

Dashboard construído a partir de uma base de 200 pedidos em Excel, mostrando em poucos segundos quanto a empresa faturou, quanto lucrou, quem vendeu mais e onde estão as vendas.

- KPIs de faturamento, lucro, ticket médio, total de pedidos e unidades vendidas
- Gráficos por vendedor, mês, produto, região e categoria, com filtros cruzados
- Medidas DAX e tratamento de dados com Power Query
- Layout do painel planejado antes no Figma/Canva

# FinanceControl
**Controle financeiro pessoal na web** &nbsp;|&nbsp; [Repositório](https://github.com/santosdev/controle-financeiro) &nbsp;|&nbsp; [Acessar o sistema](https://financecontrol-04ly.onrender.com)

Aplicação completa, com dashboard próprio de indicadores financeiros, onde cada usuário tem a própria conta, registra receitas e despesas por categoria e acompanha saldo e evolução mês a mês em um dashboard. Dá pra testar sem cadastro pelo botão **Entrar como visitante**.

- Dashboard com saldo, totais, evolução mensal e divisão por categoria, com gráficos feitos sem biblioteca externa
- Modelagem do banco em PostgreSQL com migrations versionadas pelo Flyway
- Cadastro com confirmação por e-mail, recuperação de senha e login com Google (OAuth2)
- Senhas com BCrypt, tokens salvos como hash SHA-256, proteção CSRF e Content-Security-Policy
- Bloqueio de login por 15 minutos após 5 tentativas erradas
- Cada usuário acessa apenas os próprios dados
- API REST documentada e testes com JUnit 5, Mockito e AssertJ
- Deploy com Docker no Render e banco PostgreSQL no Neon
